## Featured GitHub/Reddit/Facebook post

🚀 **Introducing JARVIS ONE v1!**

Turn your Ubuntu/Linux server into a futuristic AI command center. JARVIS ONE brings together a glowing neon HUD, hands-free-style voice interaction, configurable AI models, server-based browser tools, live outdoor weather, and real-time Bambu Lab printer status.

🎙️ Say **“Hey JARVIS”** and get a spoken greeting before your next command (browser mic permissions and HTTPS may be needed).  
🖥️ Monitor real CPU, memory, disk and uptime in one dashboard.  
🖨️ Track compatible Bambu Lab prints, nozzle/bed temps and progress.  
🌦️ Add outdoor weather coordinates in Settings without editing `.env`.  
🧠 Bring your own OpenRouter or NVIDIA AI API key.  
🔒 Host on your own Linux server using Docker.

**Free and open-source (MIT).** Get the source, Ubuntu install guide and v1 updater from the project's GitHub Releases page.
