# JARVIS ONE v1 — Quick Start

For a **fresh installation**, see [README.md](README.md) or [docs/INSTALL_UBUNTU.md](docs/INSTALL_UBUNTU.md).

For an **existing installation**, upload the separate `JARVIS_v1_FULL_UPDATE.zip` release asset using **System Updates** or use `python3 apply_update.py --file data/updates/JARVIS_v1_FULL_UPDATE.zip`. The GitHub source archive is not the update asset. Back up `.env`, data, and config before upgrading.

Keep the current JARVIS settings and volume directories; never use `docker compose down -v` when preserving data.
